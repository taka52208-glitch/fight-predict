# X手動エンゲージ Playbook（FIGHT PREDICT）

0フォロワーから抜け出すための、リプ・引用RT運用ガイド。
目的は「格闘技クラスタに認知されること」。フォロワー数より**会話に入る**ことを優先する。

---

## 1. なぜ手動エンゲージが必要か

- AdSense収益は月3桁が現実ラインなので、主戦場はABEMA PPVアフィ（1件1,000〜3,000円）
- PPVが売れるのは「大会直前にABEMAリンクを踏んでもらえる導線」ができているときだけ
- 導線 = **自分の投稿が格闘技クラスタのTLに出る**状態。0フォロワーでは自然流入ゼロ
- 突破口は2つ: ①バズる単発投稿 ②既存アカウントのTL上でリプ／引用RTして露出
- ①は運任せなので、②を毎日の運用として固定する

**KPI**: 1日10リプ / 週1回インプレッション100超の投稿 / 月1回インプ1000超

## 3. シーン別テンプレ

全テンプレに共通: **プロモは最後の1行だけ**。3行以上自分の予測・意見を書いてから `fight-predict.vercel.app` を入れる。宣伝くさいリプは即ミュートされる。

### A. 公式が試合カード発表したとき（引用RT）

```
{選手A}強いな…
直近5戦のKO率{X}% / {重要データ} で{選手B}より優位と出てる。

AIスコアだと{選手A} {XX}%。
https://fight-predict.vercel.app
#UFC #MMA
```

```
このカード、データで見ると{選手B}が意外と勝率高い。
{重要ファクト1行}

詳細出した👇
https://fight-predict.vercel.app/...
```

### B. 試合中・直後のリアクションリプ

ルール: **予測が当たったときだけ書く**。外れたときは黙る（信頼を失うだけ）。

```
{選手}の勝利予測、AIで{XX}%だった。{決着方法}も当てた。
他の試合の予測はここ👇
https://fight-predict.vercel.app
```

### C. 解説アカウントが分析投稿したとき（リプ）

相手の分析を否定しない。**追加データを足す**ポジション取り。

```
それ面白いですね。
うちのAIだと{項目}の差で{選手}{XX}%出てます。
{対戦相手}の{データ}も効いてそうです。
```

### D. 選手本人の試合前投稿（引用RT）

本人に読まれる可能性があるので、**リスペクトファースト**。

```
{選手}の試合、AI予測は{XX}%で勝利予想。
{ポジティブな戦績ファクト}が効いてる。
当日楽しみです。
https://fight-predict.vercel.app
```

### E. 試合当日の煽り投稿（独自投稿）

```
🥊 {大会名} 今日
AI予測 信頼度上位3試合👇
🔴 {選手A} 72%
🔴 {選手B} 68%
🟡 {選手C} 61%

ABEMA PPVはこちら👇
{アフィリンク}

#RIZIN #格闘技
```

## 4. 1日の動線（所要15分）

### 朝（08:00〜08:30） — Gmail確認
- `X投稿下書き` メール → 今日の1投稿をコピペして @fight_predict_ から投稿
- `的中ログ下書き` メールが来てたら、そっちを優先（的中実績は最強の差別化素材）
- **週明け月曜**: `週次的中サマリー` メール → 投稿

### 昼（12:00〜12:10） — リプ3件
- 通知ONの公式・注目選手アカウントのTLを見る
- 反応できる投稿に上記テンプレでリプ
- **新規ツイートは作らない**。リプだけで十分

### 夜（21:00〜21:15） — リプ3件 + 引用RT1件
- 1日を振り返って、自分の予測に絡められる投稿を1本引用RT
- 他アカウントのリプにさらに絡む（= 会話化）

### 試合当日（試合中）
- LIVE実況は**やらない**。速度で負けるし画像なしテキストは伸びない
- 試合終了直後に、**予測が当たった試合だけ**リプ・引用RT

## 5. NG行動（これやると1ヶ月無駄になる）

- 同じ文面の連続リプ（スパム判定）
- 公式アカウントに毎投稿リプ（ブロックされる）
- 議論・論破狙いのリプ（読者は離れる、相手のフォロワーにミュートされる）
- 試合前に外れそうな予測をゴリ押し（的中率の信用を落とす）
- 自分のURLを毎リプに貼る → 3投稿に1回まで
- 政治／社会ネタ／選手批判（格闘技以外の要素でフォロワーが荒れる）

---

## 6. 計測（週次）

毎週日曜夜に以下をメモ（スプレッドシート or Notion）:

- その週の**最高インプレッション投稿**とその内容
- フォロワー純増数
- プロフィールクリック数（X Analytics）
- `fight-predict.vercel.app` への流入（GA4 `referrer=t.co`）
- ABEMA/楽天アフィのクリック数（GA4イベント）

3週連続でフォロワー純増が0なら、**テンプレ・ターゲットを見直す**。
具体的には: bio修正 / 固定ツイート差し替え / 対象アカウントリスト入れ替え。

---

## 7. 3ヶ月目標（現実ライン）

- フォロワー 100〜300（500は6ヶ月ライン）
- インプレッション 週合計 3,000〜10,000
- ABEMA PPVアフィ成約 1〜3件／大会
- AdSense月額 数百円（本命ではない）

数字が伸びないときは**量を増やさない**。**ターゲット精度を上げる**。
リプは1日6件で十分。10アカウントを深く追うほうが100アカウントを浅く追うより効く。
