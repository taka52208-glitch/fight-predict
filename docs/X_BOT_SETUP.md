# X Bot化セットアップ手順

GitHub Actions から自動でX投稿するためのセットアップ。コードは2026-04-27に
実装済み（`.github/scripts/x_poster.py` ＋ workflow 3本に統合）。

## 仕組み

- `X_BOT_ENABLED=true` のときだけ実投稿、それ以外は noop（Gmail のみ送信が継続）
- 投稿成功時も Gmail には引き続き本文＋ステータスが届く（履歴・確認用）
- 投稿失敗時もスクリプト全体は落ちない（Gmail送信は完遂、メール本文に失敗ログが入る）
- 段階導入：先に Gmail のみ運用 → APIキー登録 → `X_BOT_ENABLED=true` で本番化

## ユーザー手作業（ブラウザ操作）

### 1. X Developer Portal で App 作成

1. https://developer.x.com/ → Sign in
2. Sign up for Free Account（無料・即時承認のことが多い）
3. ユースケース説明欄には `docs/X_BOT_SETUP.md` 末尾の英文/和文を貼付
4. Project & App 作成（App名は任意、例: `fight-predict-bot`）
5. **App settings → User authentication settings → Set up**
   - App permissions: **Read and write** （必須・Read only だと投稿不可）
   - Type of App: Web App, Automated App or Bot
   - Callback URL / Website URL: `https://fight-predict-takas-projects-de61dd0f.vercel.app`
   - Save

### 2. APIキー4点を発行

App 内の **Keys and Tokens** タブで以下4つを取得（一度しか表示されない、すぐコピー）：

- API Key（Consumer Key）
- API Key Secret（Consumer Secret）
- Access Token
- Access Token Secret

⚠️ Access Token / Secret は **「Read and write」設定の後** に発行すること。Read only のまま発行すると投稿で 403 が返る。設定変更後は再発行（Regenerate）が必要。

### 3. GitHub Secrets に登録

https://github.com/taka52208-glitch/fight-predict/settings/secrets/actions

「New repository secret」を5回押して以下を登録：

| Secret 名 | 値 |
|---|---|
| `X_BOT_ENABLED` | `false` （最初は false で仕込み、動作確認後に `true` に変更） |
| `X_API_KEY` | API Key |
| `X_API_SECRET` | API Key Secret |
| `X_ACCESS_TOKEN` | Access Token |
| `X_ACCESS_TOKEN_SECRET` | Access Token Secret |

### 4. 動作確認（X_BOT_ENABLED=false のまま）

GitHub → Actions → `x-daily-drafts` → 「Run workflow」を手動実行。
Gmail に届けば従来運用のまま。スクリプトのログに
`[x_poster] X_BOT_ENABLED != true → スキップ` が出ていればOK。

### 5. 本番化（X_BOT_ENABLED=true）

`X_BOT_ENABLED` Secret の値を `true` に更新（既存Secretの「Update」）。
次の朝8時から自動投稿開始。心配なら一度 `Run workflow` を手動実行して、
Xアカウントに投稿が出るか確認してから本番運用に移行。

## 投稿頻度の見積り

Free tier の上限は月1,500投稿。本ツールの想定：

| ワークフロー | 頻度 | 月間投稿数 |
|---|---|---|
| x-daily-drafts | 毎朝1投稿（main or card） | ~30 |
| x-hit-log | 大会翌日（月平均8大会） | ~8 |
| x-weekly-stats | 毎週月曜 | ~4 |
| **合計** | | **~42投稿/月** |

→ Free枠の3%以下、十分余裕。

## トラブルシューティング

| 症状 | 原因 / 対処 |
|---|---|
| 403 Forbidden | App permissions が Read only。Read and write に変更後、Token再発行 |
| 401 Unauthorized | Token失効 or キーミスマッチ。Regenerate して Secret 更新 |
| 429 Too Many Requests | レート制限。月1,500投稿超過か短期間連投。間隔を空けて再実行 |
| `requests-oauthlib not installed` | ワークフロー側の `pip install` が走っていない。yml確認 |
